
# Actividad 1: Juego de RA con Marcador QR 

## Descripción
Juego de realidad aumentada móvil activado por código QR personalizado. El usuario interactúa con modelos 3D recolectando postres para sumar puntos y evitando agarrar el postre equivocado.

## Herramientas que se usaron
- WebAR con MindAR
- Canva para el QR
- Poly Pizza para los modelos 3D
